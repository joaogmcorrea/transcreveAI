# Restaurar Contexto do Projeto

Use when iniciar uma nova sessão neste projeto, ou quando precisar relembrar o escopo, as decisões e as regras do projeto antes de continuar o trabalho.

## Overview

Restaura o contexto do projeto lendo, em ordem, os arquivos principais de documentação em `_docs/`.

## Passos

1. Read `_docs/CONTEXTO.md`
2. Read `_docs/MEMORIA.md`
3. Read `_docs/SCRIPTS-LOGIC.md`
4. Read `_docs/REGRAS_CONDUTA.md`
