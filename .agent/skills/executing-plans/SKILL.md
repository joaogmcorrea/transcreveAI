# Executing Implementation Plans

Use when executing implementation plans task by task.

## Overview

Execute plans from `docs/plans/` with batch execution and human checkpoints.

## Process

1. **Review**: Read plan completely. Identify risks, ambiguities. Report problems before executing.
2. **Batch**: Group 3-5 related tasks. Present and get approval.
3. **Execute**: Follow TDD cycle for each task. Announce each task.
4. **Checkpoint**: Show verification output. Get feedback. Apply corrections.
5. **Finish**: Run all project tests. Offer code review or branch finalization.

## Stop Conditions

- Missing dependency or unclear instruction
- Critical plan gaps
- Repeated verification failures

Ask for clarification instead of guessing. Never force through blockers.
